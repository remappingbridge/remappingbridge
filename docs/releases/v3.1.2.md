# RemappingBridge v3.1.2 — MNT-07

The operator formally accepted MNT-07 for versioning on **October 11, 2026**. The semantic CURRENT/CYAN palette was updated to RGB565 `0xD7FF`, a lighter pastel cyan than `0xBFFF` and brighter than `0xB65A`. The final candidate passed **87/87 host scenarios** and produced Pico 2 W firmware. Other color tokens, USB HID, BLE, persistence and navigation were unchanged.

**Operator's explicit condition:** final visual physical acceptance of MNT-07 would be concluded together with the next gate, MNT-08, which changes the focus color to normal cyan. Publishing v3.1.2 was authorized, but did **not** constitute an individual physical test of that combined visual state.
