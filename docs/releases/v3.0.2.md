# RemappingBridge v3.0.2 — MNT-02 / Remove This Help

Versão PATCH, aprovada fisicamente pelo operador em 11/10/2026; baseada na versão estável v3.0.1.

## Correções
- Na tela `REMOVE THIS MOUSE`, a dica passa a ser `KEY X: HELP` (antes `KEY Y: HELP`).
- KEY X abre `REMOVE MOUSE HELP` corretamente.
- KEY Y volta a executar o bloqueio global na tela `REMOVE THIS`, sem abrir Help.
- Durante remoção BLE pendente, KEY X e KEY Y não iniciam novas ações e a exclusão segue protegida.
- Retorno do Help conserva o mouse e o bond alvo; a tela Help ainda exibe `ANY KEY: BACK`, porque a revisão global de Helps pertence ao MNT-05.
- Mantidas as cores e a navegação de Saved Devices aprovadas no MNT-01.

## Compatibilidade
Pico 2 W, mouse BLE, HAT/LCD, identidade USB, configurações de Movement, Modifier Shortcuts e persistência v3 sem alterações. Instalação UF2 via BOOTSEL, sem apagar flash ou bonds.
