# RemappingBridge v3.0.2 — MNT-02 / Remove This Help

This PATCH release, based on stable v3.0.1, was **physically accepted by the operator on October 11, 2026**.

## Fixes

- The `REMOVE THIS MOUSE` screen now displays `KEY X: HELP` instead of `KEY Y: HELP`.
- KEY X correctly opens `REMOVE MOUSE HELP`.
- KEY Y once again triggers the global Lock on `REMOVE THIS`, rather than opening Help.
- During a pending BLE removal, KEY X and KEY Y cannot initiate conflicting actions; removal remains protected.
- Returning from Help preserves the target mouse and bond. Help still displays `ANY KEY: BACK`, because the global Help revision belongs to MNT-05.
- MNT-01's accepted Saved Devices colors and navigation are retained.

## Compatibility

Pico 2 W, BLE mouse, HAT/LCD, USB identity, Movement settings, Modifier Shortcuts, and v3 persistence are unchanged. Install with BOOTSEL/UF2 without erasing flash or bonds.
