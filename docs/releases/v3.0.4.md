# RemappingBridge v3.0.4 — MNT-04 / LCD Slash

A PATCH in the v3.x series. The operator requested publication on **October 11, 2026**, but **separate physical acceptance of MNT-04 was not recorded** and must not be inferred from the publication request.

## Changes

- Replaces backslash visual separators with slash in applicable LCD labels: JOY UP/DOWN, JOY RIGHT/LEFT, JOY LEFT/RIGHT, ENTER/RETURN, PLAY/PAUSE, and HOME SCREEN/PAGE.
- Updates the renderer's visual focus detection for RIGHT/LEFT without changing motion, navigation, or keyboard input.
- Retains backslash as a valid C/glyph/character-table character; no BLE, HID, USB, flash, profile, Movement, Modifier, or identity changes.
- The LCD remains 9 rows by 21 columns.

## Installation

Flash the production UF2 via BOOTSEL without `flash_nuke`, preserving BLE pairing, Movement, and shortcuts. No preference reset is required.

## Physical validation still pending in the original record

Check HOME CONNECTED, REMAPPING, MOVEMENT, SAVED DEVICES, COMBINATIONS, SHORTCUTS, and HELP for colors, paging, and missing truncation. Code publication is not a substitute for observing the physical hardware.
