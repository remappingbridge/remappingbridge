# RemappingBridge v3.3.0

## Scroll Inverse

Open **Movement Options**, select **Scroll Inverse OFF**, then press **Key A** to reverse vertical wheel scrolling for the connected mouse. Open **Scroll Inverse ON** and apply again to restore the normal direction. **Key B** cancels and **Key X** opens Scroll Help. Horizontal pan and Modifier wheel shortcuts keep their original directions.

Each saved mouse remembers its own setting after reconnection or restart. New mice and settings saved by earlier firmware start with Scroll Inverse off. **Reset All** in Movement Options restores normal scrolling, 1× gains and 0° rotation.

## Saved Devices

The first page shows the connected mouse. Each title combines the page number with the mouse name within 21 characters. Page left or right to inspect that mouse’s profile, horizontal and vertical DPI factors, scroll direction and rotation. All four status lines are cyan for the connected mouse and yellow for other mice. Press the joystick to open removal confirmation for the displayed mouse. An empty list shows **NO SAVED MOUSE** with removal disabled.

The operator approved manual tests for Scroll Inverse and Saved Devices on the Pico 2 W. The release workflow runs the host suite and builds the versioned UF2 and its SHA-256 checksum from the release commit.
