# RemappingBridge 3.0.0

Major firmware version for **Raspberry Pi Pico 2 W**, adding **Modifier Shortcuts** while retaining the v2 Movement Options features.

## Key features

- **12 combinations using one configurable physical MODIFIER button** in the CUSTOM profile: Modifier Released, Middle, Left, Right, Forward, Backward, Wheel Up/Down, and Move Left/Right/Up/Down.
- **30 configurable Keyboard and Consumer HID actions**, including clipboard/editing, files, screenshots, full screen, media/volume, HOME, zoom, and brightness.
- Configuration on the LCD/HAT: **HOME CONNECTED → REMAPPING OPTIONS → MODIFIER SHORTCUTS → COMBINATIONS → SHORTCUTS → KEY A: APPLY AND BACK**.
- Six combination pages and five shortcut pages; RESET SELECTED, KEY B cancel, `UNAVAILABLE` masking, and preservation of assignments even when masked.
- Exactly one MODIFIER among five physical buttons. Changing the Modifier does not erase saved shortcuts. Its associated click, scroll, or movement is suppressed when performing a shortcut.
- **v3 persistence** for CUSTOM/PASSTHROUGH profiles and 12 shortcut slots, safely migrated from v2 (legacy ESCAPE must not silently turn into MODIFIER).
- Consolidated USB HID firmware with Mouse, Keyboard, and Consumer reports, ACK/backpressure management and cancellation of synthetic events on disconnection, overflow, Lock, or reconfiguration. No additional USB debug interface.
- Saved Devices, Movement, Logitech Lift, pairing, and Help behavior retained.

## Changes from v2.0.0

- **STANDARD REMAP** and **ESCAPE REMAP** have been removed from the visible UI; **PASSTHROUGH** and **CUSTOM** remain.
- Active v2 Standard/Escape profiles migrate to PASSTHROUGH. A former ESCAPE target returns to its physical button function and is **not automatically reinterpreted as MODIFIER**.
- **Limited downgrade compatibility:** v2.0.0 does not understand the v3 shortcut schema and may restore the global profile default. Record your configuration before downgrading; lossless downgrade is not guaranteed.
- **BLE pairing:** do not use `flash_nuke` or erase the whole flash. Normal UF2 installation preserves existing BLE and Movement data.

## Compatibility and limitations

- Raspberry Pi Pico 2 W, Waveshare Pico-LCD-1.3/ST7789 240×240 display, BLE HID mouse, USB output.
- Stable USB identity with two HID interfaces; the Keyboard interface includes Consumer reports in Report mode. No new USB CDC/UART debugging interface.
- Media functions, Android HOME, application-specific zoom, and host brightness depend on the OS/application. **Zoom in Obsidian/KDE was previously reported as inconsistent** and is not considered fixed without an application-level test.
- Overall MOD-10 physical acceptance was granted by the operator; however, detailed outcomes for all 30 actions on every host platform were **not individually documented as PASS**.

## Installation

1. Download `remappingbridge-v3.0.0-pico2w.uf2` and `SHA256SUMS.txt` from this release.
2. Verify the UF2's SHA-256 against `SHA256SUMS.txt`.
3. Connect the Pico 2 W while holding **BOOTSEL**; copy the UF2 to `RPI-RP2`.
4. After restart, test HOME CONNECTED, saved mouse reconnection, Movement, CUSTOM/Modifier, and shortcuts.

**Do not erase the flash or BLE bonds** during installation or upgrades.
