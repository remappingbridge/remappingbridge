# RemappingBridge v3.2.2 — MNT-12

Physically accepted by the operator on **October 12, 2026**. This release changes **only visual indicator colors** on the 9×21 LCD.

- In **REMAPPING OPTIONS**, `MODIFIER SHORTCUTS` uses normal cyan (`0x07FF`) **only when CUSTOM REMAPPING is actually applied and a Modifier button is actually configured**. When focused, it becomes lighter cyan (`0xD7FF`). Otherwise it stays gray/white.
- In **COMBINATIONS 1..6**, only **assigned and available shortcut values** become normal cyan or lighter cyan on focus under that same predicate; labels, titles and hints retain their original colors.
- **`UNAVAILABLE`** and **`NOT CUSTOMIZED`** values retain their prior colors, even when focused. PASSTHROUGH with a stored Modifier or CUSTOM with no Modifier must not activate cyan feedback.
- An unapplied draft must not change the indicator. Per-mouse profiles, BLE HOGP, USB HID, Movement, shortcuts, persistence, navigation, text, and all other screen colors are preserved.

[Accepted candidate CI #541](https://github.com/remappingbridge/remappingbridge/actions/runs/38249366464) passed **94/94 host tests and the Pico 2 W production build**. [PR #42](https://github.com/remappingbridge/remappingbridge/pull/42). The release rebuilds firmware v3.2.2 and publishes its official UF2 and SHA256SUMS.

At the time of this release, later gates were not yet implemented at the operator's request. The subsequent MNT-13 introduced the `|` focus indicator, MNT-14 was eventually canceled, and MNT-15 remained suspended.
