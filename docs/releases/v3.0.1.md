# RemappingBridge v3.0.1 — MNT-01 / Saved Devices

A backwards-compatible PATCH on v3.0.0, physically accepted by the operator on **October 11, 2026**.

## Fix

- On `SAVED DEVICES`, both hint rows use standard system **gray**, and the sole action `REMOVE DEVICE` is **white** and implicitly selected when a saved bond exists.
- With no saved bonds (`0 OF 0`), `REMOVE DEVICE` is gray and cannot remove anything.
- The dynamic title (`1 OF N`, etc.) retains standard title **magenta**, confirmed after detecting and correcting a visual regression within MNT-01.
- Only the **connected mouse name** is cyan; other names and `PROFILE`, `DPI`, and `ROTATION` use established system colors.
- No changes to wording, pagination, BLE bonding, pairing, Movement, Modifier Shortcuts, USB/HID, or persistence. MNT-02 and other changes are excluded.

## Compatibility

- Existing Raspberry Pi Pico 2 W, LCD, and HAT hardware.
- Normal BOOTSEL/UF2 updates; **never use `flash_nuke`** for routine upgrades, to preserve bonds and preferences.
- `JOY LEFT/RIGHT` continues to page through Saved Devices, `JOY PRESS` opens `REMOVE THIS MOUSE` for the displayed bond, and `KEY B` cancels without removal.
- The versioned UF2 and checksums are release assets compiled from the final `main` SHA.
