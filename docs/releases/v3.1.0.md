# RemappingBridge v3.1.0 — MNT-05

**MNT-05 was physically accepted on October 11, 2026.** All ten Help screens display `KEY B: BACK`. Only B exits Help, Y activates Lock, and unlocking uses the global return-to-HOME flow on every screen, including Help. Other Help controls are inert. The return context and selection are preserved when B is used.

Based on v3.0.4. Candidate CI #473 passed **85/85 host tests and the Pico 2 W production build**. The release rebuilds and supplies a production UF2 and SHA256SUMS. BLE/USB protocols, persistence and Movement mathematics are unchanged.
