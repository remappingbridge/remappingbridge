# RemappingBridge 1.0

Primeira versão estável do firmware RemappingBridge para Raspberry Pi Pico 2 W.

## Destaques

- UX final consolidada em 29 telas canônicas.
- Pareamento e reconexão automática de Mouse Bluetooth HID.
- Saved Devices com nomes persistentes e Mouse conectado apresentado primeiro.
- Remoção real de dispositivos salvos, incluindo limpeza de bond/identidade e nome persistido.
- Perfis Passthrough, Standard Remap, Escape Remap e Custom Remap.
- Editor Custom com cinco botões físicos e alvo Escape via USB Keyboard sintético.
- Tratamento Logitech Lift/HID++ preservado.
- Lock global, telas Help e retorno contextual conforme a UX HOPE aceita.
- Fluxo automático SEARCHING FIRST MOUSE quando não existe Mouse salvo.
- Opção/tela de usuário Learn The Keys cancelada.
- Remoção das telas G06 obsoletas e de estados sem rota real.
- Documentação final autoritativa em `docs/hope/`.

## Hardware

- Raspberry Pi Pico 2 W
- Waveshare Pico-LCD-1.3 / ST7789 240×240

## Artefato

A release inclui o UF2 de produção:

`remappingbridge-v1.0.0-pico2w.uf2`

O firmware é compilado no GitHub Actions com toolchain e Pico SDK fixados pelo repositório.

## Qualidade

A baseline funcional foi concluída pela série HOPE, encerrada com HOPE-31 fisicamente aceito. O release build executa novamente a suíte host/arquitetura e a compilação de produção para Pico 2 W antes da publicação.
