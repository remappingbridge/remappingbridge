# RemappingBridge 1.0

The first stable RemappingBridge firmware release for **Raspberry Pi Pico 2 W**.

## Highlights

- Final user experience consolidated into **29 canonical screens**.
- Automatic Bluetooth HID Mouse pairing and reconnection.
- Saved Devices with persistent mouse names and the connected mouse shown first.
- Actual removal of saved devices, including stored bond, identity, and name.
- Passthrough, Standard Remap, Escape Remap, and Custom Remap profiles.
- Custom editor for five mouse buttons, including synthetic USB Keyboard Escape.
- Logitech Lift/HID++ handling preserved.
- Global Lock, Help screens, and context-sensitive Back per the accepted HOPE UX.
- Automatic SEARCHING FIRST MOUSE state when no mouse is saved.
- The user-facing Learn The Keys screen/option was canceled.
- Obsolete G06 screens and unreachable states removed.
- Final authoritative documentation in `docs/hope/`.

## Hardware

- Raspberry Pi Pico 2 W.
- Waveshare Pico-LCD-1.3 / ST7789 240×240.

## Firmware artifact

This release includes the production firmware `remappingbridge-v1.0.0-pico2w.uf2`. The firmware is built with the repository-pinned toolchain and Pico SDK in GitHub Actions.

## Quality and acceptance

The HOPE series established the baseline and finished with **HOPE-31 physically accepted by the operator**. The release workflow runs the host/architecture suite and the production Pico 2 W build again before publication.
