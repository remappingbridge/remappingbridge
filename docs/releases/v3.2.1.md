# RemappingBridge v3.2.1 — MNT-11

On **October 11, 2026**, the operator physically accepted MNT-11. BLE mouse names are normalized: if the case-insensitive ASCII substring `MOUSE` occurs **anywhere** in the original name, the suffix ` MOUSE` is not appended. This fixes `BTS. 0MOUSE2`, `mOuSe2`, and `MOUSEPAD`, while names like `LIFT` still receive the suffix.

HOME CONNECTED and SAVED DEVICES use the same normalizer. BLE data, bonds, IRK, per-mouse profiles/shortcuts, HID, navigation and the 9×21 LCD are unchanged.

[Accepted candidate CI #534](https://github.com/remappingbridge/remappingbridge/actions/runs/38190966788) passed **93/93 host tests and the Pico 2 W production build**. [PR #41](https://github.com/remappingbridge/remappingbridge/pull/41). The release automation rebuilds the UF2 with firmware version 3.2.1 and publishes SHA256SUMS.

Historical note: a parallel investigation was proposed after a report that PAIR NEW failed with a mouse already connected. The product contract dated September 20, 2026 requires pairing a candidate while keeping the current mouse usable until handoff. **No pairing-flow correction was included in MNT-11.** The later MNT-14 investigation was canceled following further operator testing.
