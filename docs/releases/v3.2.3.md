# RemappingBridge v3.2.3 — MNT-13

The operator explicitly accepted MNT-13 on **October 12, 2026**, after testing the candidate using the **pipe (`|`) selection marker**. This release changes only the visual focus indication in menus on the 9×21 LCD.

- Each focused navigable option gets **exactly one `|` in the first physical column**; text positions and applied options do not change.
- **A two-line option is marked on its second line only.** On the six COMBINATIONS pages, the marker belongs on value/status row **2 or 4**, not label row 1 or 3.
- `UNAVAILABLE` retains its original static color while the pipe uses the white focus color; a selected assigned value retains its lighter cyan. All MNT-12 color rules remain valid.
- Normal HOME, REMAPPING, EDIT CUSTOM, WILL BECOME, DPI, ROTATION, SHORTCUTS, and SAVED DEVICES options are marked on the focused row. In MOVEMENT OPTIONS, ROTATION remains on row 4. SAVED DEVICES marks `REMOVE DEVICE` only when a saved bond exists. Information-only screens have no marker.
- No changes to BLE HOGP, USB HID, profiles/bonds, combinations, buttons, shortcuts, Movement, storage, timing, controls, or external source code.
