# RemappingBridge v3.2.0 — MNT-10

**MNT-10 was physically accepted on October 11, 2026.** The firmware now stores profiles, remappings, drafts, Modifier settings, and the 12 combination/shortcut assignments **per Bluetooth mouse identity**, migrating the pre-existing global profile to already saved bonds.

Removing a mouse from Saved Devices clears that mouse's active profile, Movement, name and credentials, while preserving other devices. Pairing that identity again starts with defaults. Saved Devices shows the individual profile of the displayed mouse.

This compatible persistence-architecture change warranted **MINOR version 3.2.0**, without changing USB identity, menus or controls. The old global record remains inactive legacy data for migration; it is not a claim of forensic erasure of every historical byte in flash.

[Candidate CI #526](https://github.com/remappingbridge/remappingbridge/actions/runs/38190069355) passed **92/92 host tests and the Pico 2 W production build**. The release rebuilds the versioned firmware and provides UF2/SHA256SUMS.
