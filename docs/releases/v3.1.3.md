# RemappingBridge v3.1.3 — MNT-08

Em 11/10/2026 o operador aceitou fisicamente o MNT-08, concluindo também a aceitação conjunta visual do MNT-07. Agora CURRENT sem foco usa ciano normal RGB565 `0x07FF`, enquanto CURRENT selecionado fica em ciano clarinho pastel `0xD7FF`. Itens comuns continuam cinza→branco, CURRENT informativo sem seleção continua ciano normal. O fluxo de Saved Devices, e os comportamentos BLE, USB/HID e persistência estão preservados.

Código testado em [CI #498](https://github.com/remappingbridge/remappingbridge/actions/runs/38187661315), 89/89 testes host e Pico 2 W produção aprovados; firmware aprovado fisicamente pelo operador. A release recompila UF2 versionado e publica SHA256SUMS.
