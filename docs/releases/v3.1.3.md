# RemappingBridge v3.1.3 — MNT-08

On **October 11, 2026**, the operator physically accepted MNT-08, also completing the joint visual acceptance of MNT-07. An unfocused CURRENT item now uses normal cyan RGB565 `0x07FF`, while a selected CURRENT item uses pale pastel cyan `0xD7FF`. Ordinary items remain gray when unfocused and white when focused. Informational CURRENT text without selection remains normal cyan.

Saved Devices, BLE, USB/HID, and persistence are unchanged.

[Candidate CI #498](https://github.com/remappingbridge/remappingbridge/actions/runs/38187661315) passed **89/89 host tests and the Pico 2 W production build**, followed by the operator's physical acceptance. The release rebuilds the versioned UF2 and publishes SHA256SUMS.
