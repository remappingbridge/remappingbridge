# RemappingBridge v3.2.4 — MNT-15 (Generic Zoom In)

**MNT-15 was physically accepted by the operator on October 12, 2026.** This is a focused HID shortcut compatibility fix for the **Raspberry Pi Pico 2 W**, built on v3.2.3.

## Changes

- **ZOOM IN (action 26)** now sends **Left Ctrl + HID Keyboard Equal (0x2E)** with **no Shift**. The former chord was Left Ctrl + Left Shift + Equal.
- This matches the keyboard combination verified on **Obsidian under Mabox** and a browser. The browser also accepts the new chord with no Shift.
- **ZOOM OUT** remains Left Ctrl + Minus (action 27); **RESET ZOOM** remains Left Ctrl + 0 (action 28).
- The other Keyboard and Consumer actions, actual Shift-dependent commands (including REDO and SCREENSHOT AREA), USB input release/backpressure, Mouse/HID descriptors, BLE HOGP pairing, bonds, per-mouse profiles, stored shortcuts, Movement, and 9×21 display behavior are unchanged.

## Known terminal compatibility limitation

Terminals do not agree on the Zoom In shortcut: some accept **Ctrl + Equal without Shift**, while others require **Ctrl + Shift + Equal**. One application-independent HID chord cannot satisfy both behaviors. A terminal that only accepts the old Shift chord may **not** zoom in from the RemappingBridge ZOOM IN action after upgrading. Its original physical keyboard shortcut remains available. This release deliberately does **not** emit two shortcuts, detect application identity, or introduce a new menu.

The release pipeline re-runs the complete host tests and **rebuilds the production UF2 from the exact v3.2.4 release commit**. The final binary's hash will therefore differ from the earlier physical-test candidate; use the accompanying `SHA256SUMS.txt` for the official release artifact.

**MNT-14 was canceled** after successful pairing tests. This update does not modify any Bluetooth pairing behavior. All public documentation and release notes are in English.
