# RemappingBridge v3.1.4 — MNT-09

Physically accepted by the operator on **October 11, 2026**. The first option on HOME CONNECTED always reads `REMAPPING OPTIONS`, regardless of whether the active profile is CUSTOM or PASSTHROUGH.

Its navigation destination, the dynamic title based on the mouse name, Movement/Saved Devices/Pair New options, internal remapper state, USB/HID, BLE, persistence, and the v3.1.3 color rules are preserved.

[Candidate CI #505](https://github.com/remappingbridge/remappingbridge/actions/runs/38188443137) passed **90/90 host tests and the Pico 2 W production build**. The release rebuilds the versioned firmware and publishes the UF2 with `SHA256SUMS`.
