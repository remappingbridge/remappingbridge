# RemappingBridge v3.1.4 — MNT-09

Gate aceito fisicamente pelo operador em 11/10/2026. A primeira opção da tela HOME CONNECTED sempre apresenta `REMAPPING OPTIONS` (sem depender de `CUSTOM` ou `PASSTHROUGH`). Mantidos destino de navegação, título dinâmico com nome do mouse, opções Movement/Saved Devices/Pair New, estados internos do remapper, USB/HID, BLE, persistência e regras de cores da v3.1.3.

Validação candidata: [CI #505](https://github.com/remappingbridge/remappingbridge/actions/runs/38188443137), **90/90 testes host e build Pico 2 W produção aprovados**. A release recompila o firmware versionado e publica `.uf2` com `SHA256SUMS`.

PR #39: https://github.com/remappingbridge/remappingbridge/pull/39
