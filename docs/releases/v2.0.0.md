# RemappingBridge 2.0.0

Stable firmware for the **Raspberry Pi Pico 2 W** with the **Movement Options** features physically validated in gates MOV-01 through MOV-10.

## What's new

- **MOVEMENT OPTIONS** appears as the second option on connected HOME, preserving access to remapping profiles, Saved Devices, and Pair New Mouse.
- **Independent horizontal and vertical movement gain**, applied on USB axes after rotation, with `0.25x`, `0.5x`, `0.75x`, `1x`, `1.25x`, `1.5x`, `2x`, and `3x`.
- **ROTATION 0°, 90°, 180°, or 270° counterclockwise**. For example, `H=2x, V=1x, Rotation=270°` transforms a physical circular path into a horizontal ellipse.
- H/V gains and rotation persist **for each paired Bluetooth mouse identity**, surviving reconnection and restart; a new mouse uses defaults.
- **RESET ALL** returns to H=1x, V=1x, Rotation=0° and does not show a setting as applied until storage confirms it.
- **SAVED DEVICES** shows each mouse's DPI/rotation settings; **only the currently connected mouse name appears cyan**. Other screen text retains the standard yellow. PROFILE continues to show the global remapping profile from v1.
- **REMOVE THIS MOUSE** removes only the selected device and its preferences; duplicate commands are prevented, storage failures can roll back, and removal can recover when a bond disappears before asynchronous completion.
- Shared **SLOW DPI HELP**, **FAST DPI HELP**, **ROTATION HELP**, and **REMOVE MOUSE HELP** screens. The historical `ANY KEY: BACK` returns to the same screen and selection without applying changes, removing devices, or locking.
- The 9×21 character interface and release-based HAT control navigation remain intact.

## Compatibility preserved

- Passthrough, Standard Remap, Escape Remap, and Custom Remap profiles.
- Bluetooth HID connection, pairing, reconnection, and saved device naming.
- Logitech Lift/HID++, wheel/pan, clicking/dragging, and synthetic Escape.
- Existing USB HID identity, no mandatory host software or USB debugging interface.
- UF2 upgrades without wiping bonds or existing preferences.

## Hardware and installation

Raspberry Pi Pico 2 W with Waveshare Pico-LCD-1.3 (ST7789, 240×240).

Release assets: `remappingbridge-v2.0.0-pico2w.uf2` (production firmware) and `SHA256SUMS.txt` (checksum). Hold BOOTSEL while connecting Pico 2 W, copy the UF2 to the `RPI-RP2` drive, and allow reboot. **Do not wipe the full flash for an upgrade**: it would remove paired devices.

## Quality and provenance

All MOV-01 through MOV-10 gates were operator-accepted; see `remappingbridge/planner/movement-options/executions/`. The last validated functional candidate passed **59/59 host tests** and built the Pico 2 W UF2 on CI from `feature/movement-options-v1.0`. The release workflow repeats host tests and the production build against the release commit before publishing.
