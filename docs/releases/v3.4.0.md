# RemappingBridge v3.4.0

## Disable a standalone mouse click

In **Remapping Options → Custom Remapping**, open a physical button. Its **WILL BECOME** menu offers **LEFT CLICK**, **RIGHT CLICK**, **FORWARD**, **BACKWARD**, **MODIFIER**, and **DISABLED**, in that order. Choose **DISABLED** and press **Key A** to save the target. The editor shows the assignment, for example `|BACKWARD IS DISABLED`. Press **Key A: Apply Custom** to activate the profile for that mouse.

A disabled button sends no click on press or release. To use the same physical button in a shortcut, assign **MODIFIER** to a different button and configure the combination in **Modifier Shortcuts**. For example, with **BACKWARD** disabled, **MOD + BACKWARD** can still run **COPY**. The operator verified standalone suppression and the configured combination on hardware.

## Existing profiles

Saved middle-click assignments keep their original behavior until edited. The physical middle button is still available as a source for remapping and shortcuts. Previously saved modifier assignments and shortcuts retain their meanings. Selecting Passthrough restores the mouse's native button behavior.
